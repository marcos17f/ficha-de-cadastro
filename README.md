# Ficha de Cadastro

Este é um projeto simples de uma Ficha de Cadastro feito com HTML, CSS e JavaScript. O formulário coleta informações básicas do usuário e faz validações simples antes de enviar os dados.

## 💡 Funcionalidades

- Formulário com campos de nome, e-mail, telefone e senha.
- Validação de campos obrigatórios com JavaScript.
- Estilização responsiva com CSS.
- Mensagens de erro e sucesso.

## 🧪 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
